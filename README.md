# BetaHST
BetaHST Is the second version of an Hidden Source Recurrent Depth Transformer, the previous version, AlphaRDT, is a private repository. 
# What HSRDT is
The AI model is a HSRDT (A longer version of HST) Model, which is a special type of Reccurent Depth Transformer that I have developed to improve alignment in large AI models on the scale of AGI. This model works by having two AI models, one is a extremely large DQN model that evaluates neurons inside of the main model at random, 1% chance per neuron of being checked, and the main model, which is a Recurent Depth Transformer model with a head of unique weights, a body with weights that are repeated with chain-of-though thinking in vectors as many times as required by the complexity of the task, and then a tail of weights at the end to fix the instability of Recurrent Depth Transformers. The loss is determined by the combination of the loss determined by Cross-Entropy loss and the output probilibility by Softmax of the DQN model using the code <code>testing code function</code>
