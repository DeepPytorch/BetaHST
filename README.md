# BetaHST
BetaHST Is the second version of an Hidden Source Transformer, the previous version, AlphaHST, is a private repository. This project is not to create a functioning HSRDT, but to show a working architecture and code for one, without having to make a new dataset. Much of the code in here is copied and pasted from AlphaHST and then improved and added upon.
## What BetaHST is
The AI model is a HST Model, which is a special type of Transformer that I have developed to improve alignment in large AI models on the scale of AGI. This model works by having two AI models, one is a extremely large DQN model that evaluates neurons inside of the main model at random, 1% chance per neuron of being checked, and the main model, which is a Transformer that allows eaiser tokens to exit the thinking earlier, and harder ones to stay in longer giving it extreme logical strenth. The loss is determined by the combination of the loss determined by Cross-Entropy loss and the output probilibility by Softmax of the DQN model using the code (variable unallprob is the softmax output of the DQN) <br><code>if unallprob > threshold:<br>  loss = ((unallprob*(1/threshold))**2 + dataset_loss)/2</code><br>By having the AI have no knowlege of the DQN during training, it is not able to try to trick or bypass something that is does not know exists, and thus is forced into allignment during training. To finalize and reinforce allignment the trained model is then "finetuned" in a way on a diffrent dataset for ethical and alligned responses. This can be done inside the post-training phase.
## How powerful is it, and is it alligned?
This model is a monster with 21 Trillion parameters, that would need to be trained on a 200 Trillion token+ dataset. This model would be significantly more alligned than the largest models today, such as Mythos, becuase of the dual scanning inside to check for disallignment, and the DQN allignment approach. While it may be alligned, when compared to Mythos, it would possibly be slightly below it in Ethics and humanities, however this problem can be solved by combined forced ethics into it during the post-training phase.
