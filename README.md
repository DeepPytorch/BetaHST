# BetaHST
BetaHST Is the second version of an Hidden Source Recurrent Depth Transformer, the previous version, AlphaRDT, is a private repository. This project is not to create a functioning HSRDT, but to show a working architecture and code for one, without having to make a new dataset. Much of the code in here is copied and pasted from AlphaRDT and then improved and added upon.
# What HSRDT is
The AI model is a HSRDT (A longer version of HST) Model, which is a special type of Reccurent Depth Transformer that I have developed to improve alignment in large AI models on the scale of AGI. This model works by having two AI models, one is a extremely large DQN model that evaluates neurons inside of the main model at random, 1% chance per neuron of being checked, and the main model, which is a Recurent Depth Transformer model with a head of unique weights, a body with weights that are repeated with chain-of-though thinking in vectors as many times as required by the complexity of the task, and then a tail of weights at the end to fix the instability of Recurrent Depth Transformers. The loss is determined by the combination of the loss determined by Cross-Entropy loss and the output probilibility by Softmax of the DQN model using the code (variable unallprob is the softmax output of the DQN) <br><code>if unallprob > threshold:<br>  loss = ((unallprob*(1/threshold))**2 + dataset_loss)/2</code><br>By having the AI have no knowlege of the DQN during training, it is not able to try to trick or bypass something that is does not know exists, and thus is forced into allignment during training. To finalize and reinforce allignment the trained model is then "finetuned" in a way on a diffrent dataset for ethical and alligned responses. This can be done inside the post-training phase.
